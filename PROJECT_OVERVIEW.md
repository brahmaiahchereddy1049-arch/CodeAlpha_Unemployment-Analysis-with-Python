# Project Overview

## Problem Statement
Analyze unemployment-rate data in India to understand historical trends, regional differences, monthly patterns, and changes during the COVID-19 period.

## Objective
Use Python-based exploratory data analysis and visualization to transform raw unemployment data into understandable economic insights.

## Main Analysis
- Data cleaning
- Date conversion
- Missing-value handling
- Regional aggregation
- Monthly trend analysis
- COVID-period comparison
- Rural/urban comparison
- Calendar-month pattern analysis
- Labour participation relationship

## Deliverables
- Clean analysis script
- Processed summary CSV files
- Six visualizations
- Text-based findings summary
- GitHub-ready README
